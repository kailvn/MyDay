# MyDay 功能清点报告（用于与成熟软件对比分析）

> 日期：2026-09-18 · 依据：README / docs 全部 spec / 源码结构 / git log（至 22ce35a）
> 更新：2026-09-24 · 补入 回收站 / ICS 导入 / 预计时长时间块 / 日历与今天页标签过滤 / 重复规则补全（结束条件 + 单次例外）/ 即时搜索（§2 内标注「v1.2 新增」）
> 用途：给「MyDay vs 成熟软件」的对比分析提供一份自包含、按功能域分组的能力清单。
> 口径：只列**已实现**功能；未实现与明确不做的集中在 §3，对比时不得计入。

## 0. 一句话定位

个人日程 / 待办 / 记录三合一的**离线优先**桌面工具（Ubuntu GNOME 优先，兼容 Windows），
差异化在三点：**可编程**（完整 CLI + JSON + 本地 IPC，agent 可直接调用）、
**统一数据模型**（三类对象一张表 + Notion 式字段系统 + Anytype 式视图模型）、
**提醒可靠**（提醒存相对意图、去重、补发、错过聚合）。

## 1. 形态与技术栈

| 项 | 现状 |
|---|---|
| 架构 | Rust workspace：`myday-core`（模型/存储/视图引擎/提醒/IPC）+ `myday-cli` + Tauri 2 桌面端（Svelte 5） |
| GUI/CLI 同源 | 两者共享同一核心库与同一 SQLite，不存在第二套数据逻辑 |
| 窗口 | 主窗口 + 快速添加小窗 + 今日悬浮窗，共三窗口；单实例 |
| 平台 | Linux（deb）、Windows（NSIS 安装包，交叉编译）；Wayland 会话自动走 XWayland（`GDK_BACKEND=x11` 注入，可 `MYDAY_BACKEND` 覆盖） |
| 存储 | SQLite（WAL）+ 本地附件目录；时间统一 UTC RFC3339；数据目录整体可迁移（`MYDAY_DATA_DIR`） |
| 网络 | 基础功能完全离线，无账号、无云 |

## 2. 功能清单（按域）

### 2.1 对象与数据模型

- **三类统一对象**：日程 Event（开始/结束/全天）、待办 Task（截止/状态）、记录 Log（发生时间），统一一张 `items` 表，`type` 区分；9 条 CHECK + 类型不可变 trigger 下放数据库（绕过应用层直写也保证一致）。
- **类型创建即定**：录入时按内容确定性识别（填截止→待办、填开始→日程、记录字段→记录、裸文本→待办），保存前可改口一次；建错删除重录。
- **字段系统（Notion 式）**：`field_defs` 注册表，7 种字段类型（文本/数字/单选/多选/开关/日期/链接）；值存条目 `extra` JSON、键=字段 id；改名零成本；删除=软删（同名可重建、历史值保留）；内置字段（待办优先级 单选低/中/高、待办预计分钟 number 单位分钟，v1.2 新增）+ 模板物化字段（药品/剂量/距离/时长/强度/体重）；extra 值按类型严格校验，宁可报错不自动纠偏。
- **模板系统**：模板=预填充的面板（类型+列默认值+字段默认值+标签+时间占位）；时间占位是 `@token` 文法（`@now+1h`、`@d+1T09:00`、`@start+30m` 等双族语义，应用时解析为具体时刻）；随模板启用字段一次性物化；pinned 记录模板在记录页成按钮，带默认值可一键记录。
- **标签 / 附件 / 文件链接**：标签多对多；附件粘贴/拖入落本地目录（库存相对路径，多张、缩略图、双击放大、删条目级联清文件）；文件链接只记路径不复制文件（文件 / 文件夹整窗拖入或粘路径），行内 📎/📂 打开（文件夹进文件管理器）/ 📁 定位。
- **重复规则**：`@daily` / `@weekly:n` / `@monthly:d`，可带结束条件 `;until=YYYY-MM-DD`（含当天）或 `;count=N`（剩余期数，完成推进自动递减、取消完成回拨恢复；耗尽后完成=系列正常终结）（v1.2 新增）；「修改全部」语义；重复待办完成=推进下一期、取消完成=回拨一期；日历/今天页按窗口展开渲染虚拟实例。
- **重复单次例外（v1.2 新增）**：`items.recurrence_exdates`（schema v7）记录被剔除的发生锚点；重复实例详情面板提供「拆为单次条目 / 仅删除这一期」；CLI `item detach / skip --at`；ICS EXDATE 往返；窗口查询补取锚点在窗口外的重复系列（修复跨周 / 跨月重复实例不显示的既有缺口）。

### 2.2 录入与捕获

- **快速添加窗**（独立置顶小窗）：GNOME 全局快捷键 / 托盘 / 侧边栏按钮 / `Ctrl+N` / CLI `quick-add` 唤起；输入标题回车即存，时间智能默认（下一整点等）。
- **统一条目面板**：创建/编辑/模板三态同一组件；chip 激活模型（点开类型独有字段即定类型）；「＋字段」只列当前类型范围的字段。
- **时间选择器**：五行面板（日期快捷 / 迷你月历 / 时刻快捷+最近使用 / 小时×分钟网格 / 键盘导航），常用时间 3 次点击内完成；行内时间快捷标签统一三档（未来=今天/明天/后天、过去=现在/昨天/前天；日程另保留 全天/工作时间/午休 时段标签与结束相对时长，时段相对已填开始日期计算——开始指到哪天，起止就落到那天的对应钟点）；面板首页时间入口（＋时间/＋截止/＋发生时间）旁均有三档快捷：未展开首页点「今天」即一步到位（激活字段+预填+锁类型+自动展开）。
- **受控自然语言**：输入「明天9点」出提示 chip，Tab 应用，绝不静默改写标题。
- **`Ctrl+K` 命令面板**：动作+搜索结果混排，「待办 买牛奶」直达预填创建（两段确认）。
- **截图**：`Ctrl+V` 粘贴剪贴板图片为附件。
- **日历快速创建**：月格 hover 浮现「＋」、双击格子创建（锚点日带入默认值）、周/日网格空白拖选 ≥15 分钟直达创建面板。

### 2.3 日历

- **月 | 周 | 日三视图**：月网格整周显示（相邻月补位灰化但可点可拖入可创建）；周/日为时间网格（重叠自动分列、当前时刻线+时间气泡、全天块顶行）。
- **拖拽直接操控（对标飞书）**：周/日块移动（15 分钟吸附、可跨列）+ 上下边缘调时长 + 空白拖选创建；月视图当天面板行拖到日期格（日程平移 / 到期待办改截止保钟点）；重复块跨星期/日拖拽=智能改写规则并 toast 注明；松手才写库 + toast 一键撤销，Esc 放弃。
- **未排期待办池（Notion Calendar 式）**：无日期待办列在日历侧栏顶部（先进先出）；月视图拖到任意月格即排到那天 23:59，周/日视图拖到时段格即排到那个钟点（均可撤销、落点高亮 + ghost，拖出网格松手 = 取消）；到期行悬停 ＋1天 / ＋1周 / 清除，清除即退回池。待办页「无日期」内置视图同口径（FIFO）。
- **快捷键（Notion Calendar 式）**：`T`=今天、`D/W/M`=切视图、`←→`=翻页；月/周视图记忆上次浏览位置。
- **标签过滤（v1.2 新增）**：页头下拉按标签收窄——月格 chip、当天面板、周/日网格、未排期池、今天页安排/活动统一生效，「全部标签」复原。
- **时间块（v1.2 新增，对标 TickTick）**：带「预计分钟」的待办在周/日网格从截止时刻起按时长占位虚线块（重叠分列照常参与）；未排期池行显示预计 chip，拖入时段格时 ghost 按此时长占位（写库仍为截止语义，可撤销）。
- **当天面板**：单击格子显示，分「日程/到期/记录」三节；任务行勾选框就地完成/回退；行可拖拽改期。
- **法定节假日**：内置 2026 国务院安排（JSON 不硬编码），设置页可导入自定义 JSON（校验通过才生效、优先于内置）；月历/周视图 休/班 角标，今天页假期进度/倒数；数据年外优雅降级。
- **冲突检测**：保存日程与现有日程（含重复展开）相交 → 非阻断 toast 提示。

### 2.4 待办

- **四视图**：今天 / 即将到期 / 全部 / 已完成（已完成与已取消混排沉底、删除线）。
- **完成语义**：两态 todo/done；列表勾选、编辑勾选、详情按钮三处等价；重复待办完成=推进下一期。
- **批量操作**：多选 → 批量完成 / 改期（明天/+1 天/下周一/自定义，时刻保留，可整体撤销）/ 删除（入回收站，可恢复）。
- **逾期可视化**：今天页逾期待办红标「逾期」并显示完整截止时间；月格已完成 chip 灰化+删除线（红色只属于未完成）。
- **今天页状态标注**：进行中日程标「进行中」、下一个未开始标「下一个」。
- **今天页分组与折叠（v1.2 新增）**：今日安排分「日程 / 待办」两组（日程 = 当天日程按开始时间；待办 = 带开始时间的待办 ∪ 今天到期/逾期，去重、完成沉底），小标题带计数；今日活动可折叠，默认收起（标题保留计数）。

### 2.5 记录与统计

- **记录时间线**：按天分组倒序，显示时间/标题/标签/字段值/图片缩略图，按 `occurred_at` 归日（与创建时间严格分离）；记录页 pinned 模板按钮一键记录。
- **统计页（容器+挂件模型）**：页面=容器列表（横/纵布局可增删改、可重命名），挂件三段管线（数据集×聚合×渲染器）；预置热力图 / 打卡连续 / 数值趋势，同数据即时换图型（折线↔柱状↔热力）；统计范围 7–1095 天（30/90/180/365 档）；「恢复默认」完全重置。
- **CLI 统计**：`myday stats --json` 按代码预设定义求值（不随页面定制漂移）。

### 2.6 提醒与通知

- **提醒存意图（spec）**：相对规则 `@start-10m` / `@due-1h` / `@dailyT09:00` 或绝对 RFC3339，1:N 条；改期后提醒自动跟随；应用层与 DB 双向校验。
- **提醒档位（v8）**：`channel` = `notify` 系统通知 / `alarm` 闹钟（「不提醒」= 不建提醒行）；桌面条目面板提醒行直接切档，移动端快速添加「方式」选择，条目详情按档位显示 🔔 / ⏰；snooze 覆盖行继承档位（闹钟稍后仍以闹钟响）。
- **可靠性**：30 秒提醒循环；`reminder_log` 复合键去重；**补发窗口**（默认 120 分钟可调）+ **错过聚合摘要**（一条通知汇总最多 3 条，防通知风暴）。
- **桌面通知动作**：GNOME 系统通知按钮直达 完成 / 稍后提醒（+10 分钟）/ 打开定位（GNOME 受限时降级为定位）。
- **桌面闹钟档**：置顶弹窗（label `alarm`，前端按窗口 label 路由 AlarmPopup）+ WebAudio 循环提示音（关窗即停）+ critical 常驻系统通知兜底；动作 完成 / 稍后 / 打开 / 忽略。
- **安卓系统闹钟移交**（本地插件 `plugins/tauri-plugin-myday-alarm`）：提醒的调度交给系统 `AlarmManager`——notify 档 `setExactAndAllowWhileIdle`（无精确授权降级 `setWindow`），alarm 档 `setAlarmClock`（免精确授权、Doze 可触发）全屏闹铃 + 闹钟铃声 + FLAG_INSISTENT；App 进程冻结 / 被杀照常到点触发，重启后开机重排（SharedPreferences 持久化 + BOOT_COMPLETED）；改时间 / 删除 / 完成 30 秒节拍内取消已排定闹钟；前端同步失败时 Rust 侧兜底直发通知，宁重复不漏报。
- **提醒中心**：侧栏铃铛+未读角标，应用内提醒历史可定位/完成/稍后提醒（系统通知丢失的兜底）。
- **snooze**：不改相对 spec，插绝对时刻覆盖行（条目再改期不毁规则）。

### 2.7 视图模型与过滤（Anytype 式）

- **面板展示=视图求值结果**：内置视图 seed 进库是真实行，用户可直接改默认视图（`view_reset` 恢复）。
- **过滤器**：条件 AST（两层 AND/OR）、运算符随字段类型走（文本含/数字比较/选项属于/空非空…）、动态相对日期（今天/明天/N 天前，查询时求值，视图「保鲜」）。
- **多级排序 / 视图复制 / 视图重置**；工具条锚定 popover、改动即时生效、头部实时匹配数。
- **GUI 与 CLI 同引擎**：`myday item query --view <id>` 与界面同一求值、同 id 同结果。

### 2.8 搜索

- 标题/备注 LIKE + 字段名/字段值命中（extra × field_defs 关联）+ 标签独立命中；类型筛选；结果跳详情；`Ctrl+K` 混排入口 + 独立搜索页 + CLI `search`。
- **即时搜索（v1.2 新增）**：命令面板输入即出条目结果（防抖 140ms 前 8 条），搜索页免回车；两处按查询词高亮命中片段（`<mark>`，标题 / 备注 / 结果行）。刻意保留 LIKE 引擎：FTS5 unicode61 不切中文（整串成词）、trigram 需 ≥3 字符，对中文为主的个人数据量反而是退化。

### 2.9 今日悬浮窗（独有形态）

- 无边框/透明/置顶/不进任务栏/不抢焦点的第四态常驻小窗：只读展示**今日未完成**日程与待办，唯一动作=勾选完成；底部摘要行折叠所有未列出的组（逾期 N · 未安排 M，分档下叠加 日程 n / 待办 n）。
- 显示分档（全部/日程/待办）与「逾期/未安排展开成列」开关，悬浮窗 ⚙ 与设置页同款；求值口径不随分档变化。
- 透明度 30%–100% 滑杆；头部拖动定位+持久化、角落吸附重置；尺寸自由调整（默认 264×380，最小 220×280）；锁定=点击穿透；托盘开关、随启动恢复。

### 2.10 CLI / IPC / 可编程性（核心差异化）

- **命令树**：`item`（add/list/get/update/complete/convert/delete/snooze/query）/ `field` / `view` / `template` 相关 / `quick-add` / `search` / `stats` / `reminders` / `export ics` / `backup` / `ping` / `reveal`。
- **稳定机器契约**：`--json` 信封 `{ok,data}` / `{ok:false,error{code,message}}`；退出码 0/1/2/3/4；字段名向后兼容承诺。
- **agent 友好**：`--dry-run` 预览、`--idempotency-key` 幂等（重试返回已有条目）、`--stdin` JSON 输入、`--field id=值`、类型自动识别、时间严格解析不猜格式。
- **本地 IPC**：Unix socket（Windows 按平台分派）+ JSON Lines；CLI 写操作优先经运行中的 GUI 执行并广播刷新，GUI 未运行直写库；`quick-add` 可唤起弹窗预填。

### 2.11 数据安全与出口

- **ICS 导出**：VEVENT/VTODO + RRULE + VALARM + `myday://` 回链（设置页与 CLI 双入口）。
- **ICS 导入（v1.2 新增）**：本地 .ics 一次性导入，VEVENT → 日程、VTODO → 待办（无截止待办 = 进未排期池）；RRULE 映射回内置重复文法（结束条件 / INTERVAL ≠ 1 / YEARLY 等降级为告警），VALARM 相对/绝对提醒随条目导入；重复导入双重防护（myday 回链跳过 + `ics-<UID>` 幂等键）；入口：`myday import ics`（支持 `--dry-run`）+ 设置页路径导入。
- **回收站（v1.2 新增）**：删除 = 软删（`deleted_at`，schema v6 迁移），行与附件文件原封不动、提醒静默；回收站页支持逐条恢复 / 彻底删除（两步确认）/ 清空；删除超 30 天在 GUI 启动时自动彻底清理；CLI：`item delete --hard` / `item restore` / `item list --trash`；全部列表/视图/统计/搜索/窗口查询排除回收站条目。
- **一键备份**：zip（SQLite VACUUM INTO 快照 + 附件目录），保留最近 7 份。
- **删除保护**：GUI 两步确认 + 删除即入回收站（行与附件原封不动，恢复入口在回收站页）；提醒/标签/附件文件的级联清理在彻底删除（回收站内逐条或清空）时执行。
- **Schema 演进**：无迁移链，旧库 `VACUUM INTO` 备份后重建；schema 版本号判定。

### 2.12 桌面集成

- 系统托盘（快速添加、悬浮窗开关、显示主窗口）；关闭=隐藏保活；单实例。
- GNOME 原生通知（DBus）；全局快捷键走 GNOME 自定义快捷键 + CLI（Wayland 可靠路径）。
- 首次启动「选择启用模板」引导；设置页含 数据与 IPC / 节假日 / 提醒（默认提前 N 分钟、补发窗口）/ 悬浮窗 / 全局快捷键提示 / 字段与模板管理。

### 2.13 工程质量

- Rust 集成测试（core store/view + CLI 真二进制）；前端 golden 自检（holidays / recurrence / timewords / tpltime 四组）；Playwright 真 Chromium E2E（26 用例，语义定位约定，失败留 trace）；`?e2e=1` 内存 mock 支持交互式实机调试。

## 3. 未实现 / 明确不做（对比时的已知边界）

**路线图内未做**：
- 重复单次例外修改、until/次数结束（当前只有「修改全部」+ 拖拽规则改写）
- 本地 ICS 订阅导入、CalDAV/远程日历
- systemd 独立提醒守护（提醒依赖 GUI 常驻）
- 提醒 1:N 的创建路径 UI（schema 已支持，当前默认单条）、提醒通道（声音/弹窗）选择
- 字段条件筛选进日历（今天页/日历暂不接视图模型）、看板/画廊等布局、按字段分组
- 跨时区显示（按本地时区聚合）
- macOS 构建

**明确不做（需求文档钉死）**：云同步、多人协作/权限、富文本编辑器、邮件/联系人、完整自然语言解析、图片入 ICS、远程 API 服务。

## 4. 对比框架建议

**建议对比对象**（按功能域就近对标）：

| 对象 | 对比它的什么 |
|---|---|
| Google Calendar / 飞书日历 | 日历体验：拖拽、重复、节假日、提醒、全天/跨天 |
| Todoist / TickTick | 待办：视图、批量、重复推进、快速录入、自然语言 |
| Notion / Anytype | 数据模型：字段系统、视图/过滤器/排序、模板 |
| GNOME Calendar / Thunderbird | 本地离线基线：无账号能做到什么 |
| Obsidian / 专项追踪 App | 记录+统计：时间线、趋势、热力图 |

**初步定位**（对照 SPRINT2 差距表 + 本次清点）：

| 维度 | MyDay | 成熟软件一般水平 | 定位 |
|---|---|---|---|
| 拖拽改期/调时长/拖选创建 | 周/日/月全覆盖 + 撤销 | 飞书/Google 同级 | 持平 |
| 重复规则 | 三种文法 + until/count 结束条件 + 单次例外（拆分 / 跳过） | RRULE 全集+单次例外+until | 基本持平（差 RRULE 长尾：INTERVAL、多 BYDAY、YEARLY） |
| 节假日休/班 | 内置+可导入（离线反超点） | 云服务才有 | 领先（离线场景） |
| 时间录入 | 五行点选面板+受控 NL chip | 下拉/滚轮或完整 NL | 点选领先 / NL 完整度差距 |
| 提醒可靠性 | 存意图+去重+补发+聚合+应用内中心 | 云推送为主，离线弱 | 离线场景领先 |
| 通知动作直达 | 完成/稍后/打开 | 同级 | 持平 |
| 待办×日历打通 | 到期待办上日历、待办⇄日程⇄记录互转 | 飞书无打通 | 领先 |
| 记录/统计 | 三类一体+容器化挂件 | 日历类普遍没有 | 领先（差异化） |
| 字段系统/视图模型 | Notion 式字段+Anytype 式过滤 | 独立日历/待办没有 | 领先（差异化） |
| 可编程性 | 全量 CLI+JSON+IPC+幂等+dry-run，本地方言 | 仅云 API（Todoist/Google） | **离线可编程独有** |
| 数据自主 | 本地 SQLite+附件、一键备份、ICS 导出 | 导出功能普遍受限 | 领先 |
| 悬浮窗常驻 | 内置（置顶/穿透/透明） | 需第三方工具拼装 | 领先（差异化） |
| 协作/云/多设备 | 无（明确不做） | 核心卖点 | 不参战 |
| 子任务/嵌套 | 无 | Todoist/TickTick 标配 | 差距（有意后置） |
| 回收站 | 软删 30 天 + 恢复/彻底删除（v1.2） | 多数同类有 | 持平 |
| ICS 导入 | 文件一次性导入 + 幂等去重（v1.2） | 本地日历基线 | 持平（订阅仍在路线图） |
| 时间块/预估时长 | 内置「预计分钟」+ 周/日占位块（v1.2） | TickTick 卖点级 | 持平 |
| 全文检索 | LIKE 级 + 即时高亮（命令面板/搜索页输入即出） | FTS/即时搜索 | 持平（中文场景 LIKE 更准） |
| 平台覆盖 | Linux+Windows，离线单机 | 全平台+移动端 | 差距（定位不同） |
